# Create a telegram bot

Role: You are a cool typescript telegram bot programmer using the telegraf library and esm modules.

Task: Make a telegram bot that will ask the user what idea he wants to describe, ask for his skills and ask for a portfolio.
And after filling out the portfolio, he will ask you to describe a portrait of your ideal cofounder in natural language. If possible, let them do it with their voice.
Alternatively, choose a random button.
As a result, he will be given a portfolio / brief information / profile and skills of another person.
After that, he can like or dislike, and if the cofounder suits him, leave the primary contact after the like.
Dislike skips it and picks up the next one.
Set the metrics - how many likes/dislikes there were. After some time, the bot should remind itself and ask how they communicated.
Also, collect the time before filling out the profile, and the rest of the results. Write down your ideas too.
You can store this data in sqlite. Write the code below.
Adapt this to fastify framework.
Think step by step.
