* Explain the problem as you see it

Now all documents are maintained locally and they can be lost.
I propose adding the opportunity to use a special synchronization server.

* Suggest a solution

Implement the server, using a relation database with json-b support.

I propose to use schema of objects themselves from
- [[https://codeberg.org/fediverse/fep/src/branch/main/fep/ef61/fep-ef61.md][FEP-ef61: Portable Objects]]

Thereby we can increase a decentralization

Using Portable Object to save a state of watch contracts, in time property, and blocks.

For example:
