# Columine

Creating a platform for brainly documents. Dream and realize your powerful ideas on the one place.

## Tech stack

- [Astro](https://astro.build) - platform to rendering application
- [Editor.js](https://editorjs.io/) - WYSIWYG editor as a core
- [Lit](https://lit.dev/) - Building web-componenets and ui interfaces simple
- [Eslint](https://github.com/antfu/eslint-config) - Tool and preset which is code has always been perfect
- [Bun](https://bun.sh) - runtime for run any quality of code
